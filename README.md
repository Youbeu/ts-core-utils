# @yac/ts-core-utils

Zero-dependency TypeScript utility primitives for high-reliability web and backend services.

## Modules

- `array`: `chunk`, `uniqBy`, `groupBy`, `partition`
- `async`: `sleep`, `retry`, `withTimeout`, `mapPool`
- `object`: `pick`, `omit`, `deepFreeze`
- `string`: `slugify`, `truncate`
- `result`: `Result<T, E>`, `ok`, `err`
